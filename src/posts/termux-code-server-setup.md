# Setup Code Server in Termux

> ~this post is also used for my own note lol~

do you want to use vscode in your phone? welp... [code-server](https://github.com/coder/code-server) is what you're looking for!

but when you used code-server by following official guide, then you try to use code-server just the same like you've used vscode on your computer and you got many problems? some common problems like these

- extension cant work due to unsafe certificate from localhost.
- some keybinds didn't work cause browser limit some features on http protocol.
- you use termux without proot, causing some limitations on android path.

dont cry yet!!! there's hope!

first of all, let's see if you have all the requirements here:

1. [Termux App](https://github.com/termux/termux-app)
2. Access to internet

# Preperation

for preperation, we will use Debian (CLI) and for easier set this up, we will use [Andronix](https://andronix.app/) to install our debian in termux.

> If you dont have Andronix app, dont worry, the command will be available in this post.

## Debian Setup

### With Andronix App

Just follow [this official guide](https://docs.andronix.app/unmodded-distros/unmodded-os-installation).

### Without Andronix App

1. open termux, update and upgrade your packages first.

```bash
pkg upgrade -y
```

> Note:
> Upgrade command using `pkg` already do update for you, so you dont have to `pkg update` or `apt-get update`.

2. install debian cli.

```bash
pkg install wget curl proot tar -y && wget https://raw.githubusercontent.com/AndronixApp/AndronixOrigin/master/Installer/Debian/debian.sh -O debian.sh && chmod +x debian.sh && bash debian.sh
```

## Other Setup (optional)

this setup is my personal way of using code-server, like using local ip address and using alias for starting the debian.

1. create `.bashrc` file in $HOME.

```bash
cd ~ && touch .bashrc
```

2. run this command.

```bash
echo "alias debian='~/start-debian.sh'" > ~/.bashrc
```

3. modify `start-debian.sh` file using nano to be like this:

install nano

```bash
pkg install nano && nano ~/.bashrc
```

copy-paste this into the file (just select all and paste all of it):

```bash
#!/data/data/com.termux/files/usr/bin/bash
cd $(dirname $0)
## unset LD_PRELOAD in case termux-exec is installed
unset LD_PRELOAD

IP=`ifconfig 2> /dev/null | grep -Eo 'inet (addr:)?([0-9]*\.){3}[0-9]*' | grep -Eo '[0-9.]*' | grep "192.168"`;
if [ -z "$IP" ]; then
  IP="0.0.0.0"
fi

command="proot"
command+=" --link2symlink"
command+=" -0"
command+=" -r debian-fs"
if [ -n "$(ls -A debian-binds)" ]; then
    for f in debian-binds/* ;do
      . $f
    done
fi
command+=" -b /dev"
command+=" -b /proc"
command+=" -b debian-fs/root:/dev/shm"
## uncomment the following line to have access to the home directory of termux
#command+=" -b /data/data/com.termux/files/home:/root"
## uncomment the following line to mount /sdcard directly to /
command+=" -b /sdcard"
command+=" -w /root"
command+=" /usr/bin/env -i"
command+=" HOME=/root"
command+=" PATH=/usr/local/sbin:/usr/local/bin:/bin:/usr/bin:/sbin:/usr/sbin:/usr/games:/usr/local/games"
command+=" IP=$IP"
command+=" TERM=$TERM"
command+=" LANG=C.UTF-8"
command+=" /bin/bash --login"
com="$@"
if [ -z "$1" ];then
    exec $command
else
    $command -c "$com"
fi
```

> Note:
> If you use something like this, when you start the debian server, you'll have $IP variable and it could be used to start your code-server local address.

finally you could start debian with `debian` command!

# Code Server

This part is the main content of this post. You'll install [code-server](https://github.com/coder/code-server) and [mkcert](https://github.com/FiloSottile/mkcert).

> Note:
> You should already in debian server at this part.

## Install Code Server

```bash
curl -fsSL https://code-server.dev/install.sh | sh
```

## Install mkcert

- for 64-bit device:

```bash
apt install libnss3-tools && curl -JLO "https://dl.filippo.io/mkcert/latest?for=linux/arm64" && chmod +x mkcert-v*-linux-arm64 && cp mkcert-v*-linux-arm64 /usr/local/bin/mkcert
```

- for 32-bit device:

```bash
apt install libnss3-tools && curl -JLO "https://dl.filippo.io/mkcert/latest?for=linux/arm" && chmod +x mkcert-v*-linux-arm && cp mkcert-v*-linux-arm /usr/local/bin/mkcert
```

## Setup Certificate Client

you have to install client certificate that are generated by mkcert into any device that you want to use code-server with. first of all, let's generate the client certificate with mkcert.

```bash
mkcert -install
```

then you have to manually install `rootCA.pem` into device certificate.

1. go to Password and Security > System Security > Credential Storage > Install certificate from storage > CA certificate.

> Note:
> This could be vary on different devices and android versions, if that the case, just search the setting name with keyword "Certificate" and choose the one that have "Install" in there.

2. look the `rootCA.pem` file in termux directory (swipe the file drawer from left to right, reversed if you're using right-to-left layout), the file is located in <b>Termux/debian-fs/root/.local/share/mkcert/rootCA.pem</b>.

## Setup Code Server

1. create `.bashrc` file in $HOME (this one is not termux $HOME, but our debian $HOME which is /root)

```bash
cd ~ && touch .bashrc
```

2. write .bashrc file with all of this code using nano

```bash
http_proxy="";
https_proxy="";
VSCODE_PROXY_URI="";

function code() {
  P=12345;
  export http_proxy="http://${IP}:${P}";
  export https_proxy="https://${IP}:${P}";
  export VSCODE_PROXY_URI="${IP}";
  echo "Proxy: ${VSCODE_PROXY_URI}";
  mkcert $IP;
  code-server --auth none --cert ~/$IP.pem --cert-key ~/$IP-key.pem --disable-getting-started-override --disable-telemetry --ignore-last-opened --bind-addr $IP:$P --trusted-origins $https_proxy;
}
```

> Note:
> You could modify the command as you want. for example, the P variable is your port, this command will use 12345 as the port, you could modify it to something else like 8080, 9000, etc.

3. finally you could start code-server by just running `code` command.

```bash
code
```

it will show you the url that could open the code-server!
